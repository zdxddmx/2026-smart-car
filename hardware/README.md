# 智能汽车竞赛 · 电磁组硬件设计

全国大学生智能汽车竞赛电磁组自研板卡，全部使用嘉立创 EDA 完成原理图与 PCB 设计并打样焊接。
立创 EDA 工程文件可直接双击打开。

## 板卡清单

| 文件 | 用途 |
| --- | --- |
| `ProPrj_DRV8701电机双驱.epro` | DRV8701 双路电机驱动板 |
| `ProPrj_DRV8701E双驱，曙光.epro` | DRV8701E 版本双驱（改进版布局） |
| `ProDoc_DRV8701单驱2_2025-04-30.epro` | DRV8701 单驱方案 |
| `ProPrj_4路分体电磁循迹模块.epro` | 4 路电磁循迹模块（分体设计） |
| `ProPrj_OPA4377运放改良.epro` | OPA4377 信号调理电路，改良后提升电感信号信噪比 |
| `ProPrj_STC电磁2.0挖孔.epro` | 主控板，挖孔轻量化处理 |

## 说明
